# Портал ГМЗ-1

Стартовая страница со всеми приложениями завода: мои разработки, приложения ГМЗ-1, приложения НГМК и полезные ссылки.

![Скриншот](docs/screenshot.png)

## Возможности

- **Командная строка** — `Ctrl + K` или `/`: поиск приложений, ссылок и команд, выбор стрелками, `Enter` — открыть
- **Проверка доступности** — у каждого приложения зелёная («В сети») или красная («Нет ответа») точка; кнопка ⟳ проверяет заново
- **Избранное** — звёздочка на карточке; приложения из избранного открываются клавишами `1`–`9`
- **Недавно открытые** — быстрый доступ к последним приложениям
- **Витрина** для раздела «Мои разработки» (крупные карточки, `featured: true` в настройках)
- Карточки с 3D-наклоном и подсветкой за курсором, живой фон, анимированная статистика
- Боковое меню с подсветкой текущего раздела; на телефоне — выезжающее меню
- Вид «плитки» или «список», светлая и тёмная тема (выбор запоминается)
- Работает **без интернета**: нет внешних библиотек, шрифтов и CDN

> Проверка доступности работает, когда портал открыт с веб-сервера по `http://`. Если портал открыт по `https://`,
> браузер не даст проверить приложения на `http://` — их можно исключить через `check: false`
> или отключить проверку целиком: `checkStatus: false` в `js/config.js`.

## Как добавить своё приложение

Откройте `js/config.js` и добавьте объект в нужный раздел (например, «Мои разработки»):

```js
{
  name: "Учёт реагентов",
  description: "Приход и расход реагентов по цехам",
  url: "http://10.0.0.15:8080",
  icon: "flask",
  color: "green",
  status: "new",
  tags: ["склад", "химия"],
},
```

Список иконок и цветов — в комментарии в начале `js/config.js`.
Новый раздел добавляется так же: скопируйте блок `{ id, title, description, icon, apps: [...] }`.

> У старых приложений сейчас стоит адрес `"#"` — это заглушки, замените их на реальные адреса.

## Запуск

Достаточно открыть `index.html` в браузере. Для доступа всем сотрудникам положите папку
на любой веб-сервер внутренней сети (IIS, nginx, Apache) — сборка не нужна.

```
index.html
css/style.css
js/config.js   ← настройки и список приложений
js/icons.js    ← иконки
js/app.js      ← логика страницы
```
